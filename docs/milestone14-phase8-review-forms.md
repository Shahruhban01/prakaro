# Phase 8 review forms and evidence

The declarative field model supports short text, long text, select, multiselect, checkbox, radio, number, date and case evidence reference. It has stable field IDs, labels, descriptions, required flags, typed defaults and bounded options and values. Conditional fields reference earlier valid fields. Hidden answers are excluded by the console and rejected if submitted as extra inputs. A required checkbox means affirmation. The backend validates the submitted answers against the pinned document.

Evidence rules can be required or optional, apply to specific actions or tags, depend on form answers, and set a minimum count. Current approved independent evidence and an actual reporter explanation are supported as required evidence. Photos, ownership documentation, location and external attribution are optional guidance until a trusted source can supply typed evidence. The console and server never treat a configured category as evidence on its own.

Independent evidence must belong to the existing case, be current and come from a supported independent source. Configured rules may strengthen the requirements. The canonical parking publication workflow still enforces independent verification even if a policy lists no required evidence. QA and existing model confidence cannot grant a Verified badge.
