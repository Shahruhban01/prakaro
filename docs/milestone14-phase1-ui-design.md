# Moderation workspace

The shared shell uses a neutral sidebar and content area, white surfaces, compact tables, blue primary actions and a responsive workspace header. Directory filters live in the URL.

| Route | Screen |
| --- | --- |
| /dashboard | Scoped workforce metrics and activity |
| /organizations, /organizations/:id | Organization directory and edit |
| /lobs, /lobs/:id | LOB directory, editing and organization assignment |
| /staff, /staff/:id | Employee directory, provisioning and membership |
| /teams, /teams/:id | Team directory and employee, manager and supervisor assignments |
| /queues, /my-tasks, /qa, /escalations | Existing operational workflows |
| /analytics, /settings/ai, /settings/permissions, /audit-log | Existing analytics and platform surfaces |

The existing case workbench remains reachable through authorized links. The redesigned shell wraps all authenticated routes. Notifications explicitly indicate availability.
