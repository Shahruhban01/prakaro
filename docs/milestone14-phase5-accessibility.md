# Phase 5 accessibility

The workspace uses headings, associated field labels, grouped controls, required hints and status announcements. Elapsed time updates visually without announcing each second. The case heading receives focus when a different reservation loads. The confirmation dialog focuses the safe action and accepts Escape while idle. The photo dialog accepts keyboard navigation and announces loading or unavailable media.

Alt + Shift shortcuts focus the decision field (D), tag search (T), submit action (S), or policy reference (P). Text entry and dialogs take priority over shortcuts. Publishing requires an explicit button action. Focus outlines and scroll padding account for the sticky header and action bar. These measures follow applicable principles in the [WCAG 2.2 recommendation](https://www.w3.org/TR/WCAG22/). Automated checks do not constitute a full accessibility audit.
