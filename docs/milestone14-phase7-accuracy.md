# Phase 7 accuracy and coverage

| Metric | Definition |
| --- | --- |
| Finalized accuracy | Current finalized Pass count divided by finalized Pass plus Fail |
| Sampling coverage | Randomly selected decisions divided by eligible decisions under an enabled policy at completion |
| Sampling processed | Eligible decisions with a recorded automatic draw |
| Dispute overturn rate | Overturned disputes divided by resolved disputes |
| Correction rate | Completed corrections divided by finalized evaluations |
| QA handling | Mean assessment elapsed seconds |
| Moderator AHT | The existing Phase 6 sum of eligible handling seconds divided by eligible completions |

Group results sum Pass and Fail counts before dividing, so a reviewer with one evaluated item carries one item of weight. Open disputes are absent from accuracy until resolved. An overturned Fail becomes a finalized Pass, while the original assessment remains visible. QA passes, failures, and manually selected cases contribute to finalized sample accuracy. The mix can differ from the full population and is not an estimate of all decisions without a representative sampling design.

A zero denominator returns unavailable. Scope, eligible count, and sample counts accompany percentages. Time filters use the original completion date in UTC, and organization and LOB retain work-time attribution. Team comparisons use current roster membership. Coverage is shown only when the actor can view both population and sample under the same scope. Dispute, assessment, and correction elapsed time are separate from continuous-case handling.
