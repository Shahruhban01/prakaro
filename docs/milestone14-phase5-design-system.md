# Phase 5 workspace design

The workspace uses the workforce palette, Inter typography, existing AUX popover and Lucide icons. A sticky case header presents queue, case, elapsed seconds, session total and connection or lease information. Evidence has the wider column. Both columns become one at a viewport width of 950 pixels or less. The global AUX control retains its clock and lock indicator on mobile.

The scrollable workforce main region contains the evidence and policy panels. The action bar stays at the bottom of this region. Submit and Submit & Leave share a group, with the release action separated by position and color. Buttons have visible text and focus indicators. Status labels convey meaning independently of color. Images use contained previews and a viewport-sized native dialog when authorized media is supplied.
